# Only the games tables have filters

- The filters box is on the games tables only: the games page's, a team's and a group's.
- The other tables (standings, groups, a roster, the scoreboard, the dialogs') only sort.
- Why: the user wants them off by default; those tables are short enough to scan, and the box crowds them.
- Revisit when another table grows long enough that sorting can't find a row.
